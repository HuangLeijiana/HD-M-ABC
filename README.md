# HD-MABC：假设驱动的记忆增强蜂群优化框架

> **当前状态：V1 概念假说 / 技术报告。**  
> 本仓库当前内容用于明确研究对象、架构边界和后续实验计划；尚未提供实验结果，也不声称该方法已经优于现有算法。

## 项目简介

HD-MABC（Hypothesis-Driven Memory-Augmented Bee Colony Framework）是一套面向“连续相关优化任务”的人工蜂群优化（ABC）概念框架。它试图解决传统群智能优化器在任务切换时“从零开始、缺少可复用经验、难以修正错误先验”的问题。

核心思想是：优化器不应只保存历史最优解，而应维护一套**可选择、可遗忘、可质疑、可验证**的长期记忆。历史经验被视为“区域级假设”，而不是永远正确的知识。当新任务中的观测与旧记忆发生冲突时，系统应生成可检验的替代假设，并用有限预算的分支搜索去验证。

## 核心问题

HD-MABC 关注三个研究问题：

1. **跨任务学习**：如果连续任务之间存在可复用结构，带有选择性记忆的优化器能否减少达到目标误差所需的函数评估次数？
2. **避免被记忆误导**：当历史规则在新任务中变得错误或过时，优化器能否检测冲突并主动测试替代解释？
3. **假设驱动跃迁**：在欺骗性搜索空间中，冲突触发的分支探索是否会带来可观测的收敛曲线跃迁？

这些问题目前是**待验证假说**，后续需要通过实验支持或反驳。

## 架构概览

HD-MABC 将优化过程划分为四层：

1. **任务层（Task Layer）**  
   定义当前优化目标、搜索边界、约束、预算、终止条件和任务元信息。

2. **记忆系统（Memory System）**  
   包含短期记忆缓冲区和长期结构化知识库。短期记忆保存当前运行中的样本与证据标签；长期记忆保存跨任务可复用、可修正的区域规则。

3. **决策与探索引擎（Decision & Exploration Engine）**  
   根据任务上下文和记忆信号决定利用、规避、重新测试或发起分支搜索。完整架构中可扩展自适应机制、强化学习元控制器、量子启发搜索或大模型辅助接口，但第一版原型不依赖这些高级模块。

4. **执行层（Execution Layer）**  
   保留人工蜂群算法中的雇佣蜂、观察蜂和侦察蜂结构，同时增加证据回传、记忆更新和有限预算分支搜索能力。

## 关键机制

### 1. 选择性记忆与遗忘

系统不会无差别保存所有历史样本，而是将证据标记为：

- 正向知识：产生高质量解或稳定改进的区域、样本或操作；
- 负向知识：经过充分测试但表现不佳的区域；
- 噪声 / 垃圾信息：与目标弱相关、受噪声支配或难以指导未来决策的观测。

长期记忆需要随时间衰减，并在反复失败、被新证据否定或被更强规则替代时被降权、标记为不确定或删除。

### 2. 认知冲突检测与假设生成

冲突发生在“记忆预期”和“当前观测”不一致时，例如：

- 高潜力区域连续失败；
- 低潜力区域出现意外高质量样本；
- 当前样本分布明显偏离历史统计；
- 系统遵循高置信度记忆后仍持续停滞。

冲突不直接等于结论，而是触发可检验假设，例如“旧记忆过时”“当前任务是例外”“观测只是噪声”“区域划分过粗”等。

### 3. 有限异步分支探索

当系统生成多个假设时，不应无限制探索，而应为每个假设分配固定预算的分支蜂群。分支结束后，根据解质量提升、记忆置信度变化、冲突是否被解释以及消耗预算进行仲裁。

这一机制的目标不是穷尽搜索，而是在记忆可能误导搜索时，用有限成本进行证据驱动的自我修正。

## 第一版原型目标

后续实现应优先保持简单、可调试、可复现：

- 实现标准 ABC 基线；
- 添加短期证据标签；
- 使用区间或超矩形表示长期记忆规则；
- 实现记忆置信度、使用次数、矛盾次数和遗忘机制；
- 实现冲突检测与固定模板假设生成；
- 实现带固定预算和确定性随机种子的分支蜂群；
- 记录每次冲突、假设、分支预算、分支结果和记忆修改。

第一版不应过早引入过多高级模块，否则难以判断性能变化到底来自记忆、冲突检测、分支搜索还是额外模型能力。

## 待验证猜想

### 猜想 1：记忆加速效应

在一系列相关优化任务中，选择性记忆应帮助优化器逐渐减少达到预设误差阈值所需的函数评估次数。

建议验证方式：

- 构造至少 8 个相关连续优化任务；
- 每个任务记录 evaluations-to-target；
- 每个算法和任务至少进行 30 次独立运行；
- 与标准 ABC、仅记忆版本、无冲突检测版本等进行对比；
- 使用趋势检验判断评估次数是否随任务序列显著下降。

若带记忆算法没有显著下降趋势，或标准 ABC 也出现相同趋势，则该猜想不成立或证据不足。

### 猜想 2：假设跃迁效应

在欺骗性优化场景中，如果长期记忆错误地将全局最优所在区域标记为低潜力，那么具备冲突检测与分支探索的系统应能在发现矛盾后修正先验，并在收敛曲线上表现出明显的误差下降跃迁。

建议验证方式：

- 人为植入错误低潜力记忆；
- 将全局最优放入被惩罚区域；
- 在其他区域设置较宽的局部最优；
- 记录冲突触发时间、生成假设、分支预算、被接受分支和 best-so-far 误差曲线；
- 使用变点检测或冲突前后斜率比较判断是否存在显著跃迁。

若跃迁无法与普通随机发现区分，则该猜想不成立或证据不足。

## 实验路线图

1. 实现干净的标准 ABC 基线；
2. 添加短期记忆与长期区间记忆；
3. 实现选择性遗忘和置信度更新；
4. 实现冲突检测和假设模板；
5. 实现有限预算分支蜂群；
6. 运行记忆加速实验和假设跃迁实验；
7. 发布随机种子、原始日志、绘图脚本和统计检验代码；
8. 只有在结果可复现后，再更新报告中的实证结论。

## 声明边界

请注意：

- HD-MABC 当前是一个**架构假说**；
- PDF 中的两个效应是**预测**，不是结论；
- 后续实验可能支持这些猜想，也可能反驳它们；
- 负结果同样重要，因为它能暴露记忆表示、冲突阈值、分支预算或任务设计中的问题；
- 若任务之间没有可复用结构，记忆可能没有帮助，甚至可能伤害搜索。
